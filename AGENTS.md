Issues are tracked in GitHub Issues. See `docs/agents/issue-tracker.md`.

### Triage labels

Use the five canonical triage roles. See `docs/agents/triage-labels.md`.

### Domain docs

This is a single-context repository. See `docs/agents/domain.md` and `CONTEXT.md`.

## Engineering workflow

- Research statutory or technical claims from current primary sources.
- Use test-driven development for behaviour changes and bug fixes.
- Diagnose failures before changing implementation.
- Review changes against both the requested specification and repository standards.
- Preserve accounting controls, refusal paths and human review boundaries.
- Require explicit approval for releases, merges and other remote account changes.
