# Triage labels

Apply one of these five triage outcomes after reading an issue. Existing type
labels such as `bug`, `documentation` and `enhancement` may accompany them.

| Role | GitHub label | Meaning |
| --- | --- | --- |
| Needs triage | `needs-triage` | The report has not yet been assessed. |
| Needs information | `needs-info` | Reproduction, source evidence or a material fact is missing. |
| Ready for agent | `ready-for-agent` | The work has clear acceptance criteria and no human-only decision. |
| Ready for human | `ready-for-human` | The work requires professional judgement, statutory interpretation, release approval or another human decision. |
| Will not fix | `wontfix` | The repository will not take this work forward. |

Do not use a label to imply that an accounting result, payment, lodgment or
professional conclusion has been approved.
